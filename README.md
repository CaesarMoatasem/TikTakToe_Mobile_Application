# TikTakToe_Mobile_Application
An Android Tic-Tac-Toe app in Java with Firebase login and registration. Play 2-player on one device or against a Gemini-powered AI at three difficulty levels. It has win, lose and draw sounds, dark mode, four languages (EN, FR, DE, TR), and a history screen with per-player stats and pie charts, all saved in Firestore.
